# Sweet Haven Bakery

A complete, responsive static website for a fictional artisan bakery.

## Pages

- `index.html` - home page with hero, featured products, story, and CTA
- `products.html` - menu with category filtering
- `gallery.html` - image gallery with lightbox modal
- `about.html` - bakery mission, history, and team highlights
- `blog.html` - recent posts list
- `blog/*.html` - individual blog post pages
- `contact.html` - contact form, business hours, map, and details

## Structure

- `css/` - primary and responsive styles
- `js/` - navigation, filtering, lightbox, and form validation scripts
- `assets/images/` - local placeholder SVG images
